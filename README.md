## ⚡ Key Features

- **Version Control:** Native Git integration with visual diff, blame, and merge conflict resolution.
- **Terminal Emulator:** Built-in terminal with split panes, custom shells, and command history.
- **Database Explorer:** Visual query builder, schema browser, and data export capabilities.
